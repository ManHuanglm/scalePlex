# UniScale 条码秤管理软件｜开发任务清单（Trello / 飞书可用）

**优先级定义**

- **P0**｜阻塞里程碑，必须先做，核心底座

- **P1**｜一期核心功能，交付可用版本（替代 TOP2000）

- **P2**｜二期扩展，增加托利多 / CAS 等外贸秤

- **P3**｜三期增值功能，可选，按需开发

**工时单位：**人天（1 人全职，不含联调等待、实体秤调试排队时间）。

**看板建议：**Trello 列表【待规划】→【进行中】→【自测完成】→【联调测试】→【已上线】；飞书任务可直接复制导入，支持分配、截止时间与标签（优先级 / 模块）。
